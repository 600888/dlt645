# 更新日志
## [2.0.0] - 2026-8-1
#### 新增
- 日志默认关闭，开放配置接口：`configure_logging` / `enable_logging` / `disable_logging`
  （支持设置级别、统一日志文件、关闭输出；兼容 `Log.enable_log/disable_log/set_log_level`）
- 按 DL/T645-2007 文档补全命令（客户端+服务端）：
  - 广播校时（C=08H，客户端发起，含广播地址处理与服务端 set_time 实现）
  - 冻结命令（C=16H，含广播冻结、周期冻结）
  - 更改通信速率（C=17H，支持 1200/2400/4800/9600/19200 bps）
  - 最大需量清零（C=19H，客户端命令）
  - 电表清零（C=1AH，02级权限校验，保留电表清零事件记录）
  - 事件清零（C=1BH，02级权限校验，支持总清零/分项清零，保留清零类记录）
- 传输层新增 send_only 接口（广播命令只发送不等待应答）
#### 修改
- 修正最大需量清零控制码：0x10 -> 0x19（DL/T645-2007 标准）
- 修复日志格式：调用位置含 `<module>` 等尖括号时不再触发 loguru 颜色解析错误
