## 数据定义维护

Python 版 `python/src/config/` 是 00–04 类数据定义的维护源。修改这些定义后，在仓库根目录运行：

```bash
python cpp/tools/generate_type_definitions.py
```

生成结果是 `cpp/include/dlt645/model/type_definitions.h`，需要与 Python 定义一起提交。C++ 构建及运行不需要 Python。03/04 类值以定长十进制数字字符串表示；多字段 DI 按定义顺序传入字符串列表，事件成对字段用 `first,second`。单帧数据域最多 255 字节，超过上限的事件记录需要后续增加分帧读取。
