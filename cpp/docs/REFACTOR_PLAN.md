## 数据定义维护

Python 版 `python/src/config/` 是电能、需量和变量类型的维护源。修改这些定义后，在仓库根目录运行：

```bash
python cpp/tools/generate_type_definitions.py
```

生成结果是 `cpp/include/dlt645/model/type_definitions.h`，需要与 Python 定义一起提交。C++ 构建及运行不需要 Python。当前仅转换 C++ 已实现的电能、需量和变量类型；参数及事件记录需要在实现相应 C++ 业务能力时单独设计与验证。
